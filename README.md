# Huffman File Compressor

A simple web application that compresses and decompresses text files using the Huffman Coding algorithm.

## Features

- Compress `.txt` files into `.huff` files
- Decompress `.huff` files back to the original file
- Simple web interface
- Huffman algorithm implemented in C++
- Flask used for the backend

## Tech Stack

- HTML
- CSS
- Python
- Flask
- C++
- Huffman Coding
